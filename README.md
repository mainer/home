# 我们的小屋 · 恋爱记事

一间用 CSS 3D 搭出来的「写实小屋」：木地板、窗、矮柜、串灯，墙上挂满拍立得。
点任意一张照片，就能展开那一天的日期、地点和你们写下的文字。

有两种用法：

| 用法 | 说明 |
|---|---|
| **本地版**（现在就能用） | 双击 `index.html` 打开，数据存在浏览器里，只有这台电脑能改 |
| **线上共用版**（推荐） | 部署到你自己的域名，输入暗号进入，**两个人手机、电脑都能随时加照片**，改完自动同步 |

线上共用版已经写好了后端（Cloudflare Pages Functions + KV），按 [DEPLOY.md](DEPLOY.md) 一步步点，约 20 分钟、一年只花域名钱。

## 一、本地打开

**最简单**：双击 `index.html`（推荐 Edge / Chrome）。

**想更稳**：在这个文件夹里起一个本地服务：

```powershell
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000
```

## 二、怎么更新内容

### 添加一条回忆
1. 点右上角 **编辑**（按钮会亮起来，底部出现编辑条）。
2. 点墙上那张虚线框 **＋ 新的回忆**（或底部「＋ 新回忆」）。
3. 填日期、地点、标题、想写的话，把照片拖进虚线框（可多张，第一张挂墙上）。
4. **保存**。照片会被压到 ~1400px 再存，省空间也更顺滑。

### 修改 / 删除
- 编辑模式下，每张照片右上角有 **✎**（改）和 **✕**（删）；
- 点开照片 →「编辑这条」也可以；
- 时间线里每一条也有「编辑 / 删除」（编辑模式下显示）。

### 改标题、副标题、开始日期
右上角 **小屋设置**：「在一起的第一天」会影响左下角的天数。

### 备份
页脚 **导出备份** → 得到一个 `.json`（照片也在里面）；换设备/换电脑用 **导入备份**。

> 本地模式下，清浏览器数据、换浏览器、无痕模式都会让数据消失，记得定期导出。
> 云端模式不受影响，数据在 Cloudflare KV 里。

## 三、文件结构

```
our-room/
├─ index.html              页面骨架
├─ assets/
│  ├─ css/style.css        房间 3D、光影、时间线、弹窗、口令门样式
│  ├─ js/data.js           示例数据（默认内容）
│  ├─ js/api.js            云端同步（没部署后端时自动退回本地）
│  ├─ js/app.js            渲染、编辑、保存、备份、视差
│  ├─ textures/            墙面抹灰、木地板纹理（程序生成）
│  └─ photos/              示例照片
├─ functions/api/state.js  Cloudflare Pages Function：读写 KV、校验暗号、版本冲突
├─ _headers / robots.txt   禁止搜索引擎收录、缓存策略
├─ wrangler.toml           命令行部署用（可选）
├─ DEPLOY.md               部署到域名的完整步骤
└─ preview.png             首屏截图
```

配套的小工具在上一层的 `our-room-tools/`（生成纹理、本地模拟后端），不需要部署。

## 四、几个小设计

- **视差**：鼠标在首屏移动时，整个房间会极轻微地跟着动；
- **推镜**：往下滚，镜头朝墙前推一点，再过渡到时间线；
- **胶片颗粒 + 暗角**：全站一层很淡的噪点和压暗，接近胶片照片的质感；
- **墙上排版**：照片位置按「数量 + 屏幕比例」自动算，加得越多自动排成更多行，不会乱；
- **同步冲突**：两台设备同时改，后保存的一方会看到「用云端的 / 用我这边的覆盖」二选一，不会静默丢数据。
